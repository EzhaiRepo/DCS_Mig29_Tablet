MiGTablet 0.6.20 — release candidate

Run MiGTablet-0.6.20-Setup.exe with this update folder beside it. DCS must be closed
to install/remove. Select all and Clear all only change checkmarks; Apply selection
performs installation. Per-feature install/uninstall and full restore remain.

Weapon Pack 1: JDAM, LGB, HARM and SLAM (stock-weapon integration).
Weapon Pack 2: FAB-UMBK, SCALP/Storm Shadow and JDAM-ER.
Both packs include the same shared weapon support where needed. Pack 2 can be used
without the Pack 1 ZIP. The checklist groups the backend component IDs into these
two choices. Existing partial weapon selections migrate to their corresponding pack.

Browser and Music remain separate optional ZIPs. Toki uses complete model files.
The distribution excludes static stickers, sticker generator and experimental
cargo camera. Old cached definitions cannot make these features selectable again;
managed files from retired features are restored/removed during Apply. Keep original
Manager backups and caches. User music and unmanaged personal assets are preserved.

The internal baseline and update family stay compatible with 0.6.19. DCS is pinned
to 2.9.31.29434. This is not a promise of compatibility with future DCS versions.
SLAM is marked flight-tested based on the user's report. Other outstanding live
checks (including browser FPS/VR and shutdown behavior) remain as documented in
prior updates. Installer/package tests do not establish all in-game features ready.
Nothing is published or installed by preparing this candidate. Original third-party
asset rights/credits remain with their owners; compatibility work uses OpenAI Codex.
